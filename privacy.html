Privacy Policy

Last updated: October 24, 2026

This application is used only by its owner to back up personal data from a home server to the owner's own Google Drive account.

Data accessed

The application uses the Google Drive API with the drive.file scope, so it can only access files it creates. It does not read, collect, or access any other files in the account.

Data sharing

No data is sold, shared with, or transferred to any third party. Backups are encrypted before upload and stored only in the owner's Google Drive.

Data retention and deletion

Old backups are deleted automatically on a schedule. Access can be revoked at any time at myaccount.google.com/permissions.
